สวัสดีค่ะ ฉันชื่อกษิรา

นักศึกษาวิศวกรรมไฟฟ้าสื่อสาร | ผู้เริ่มต้นเขียนเว็บ

ฉันกำลังศึกษาอยู่ชั้นปีที่ 4 สาขาวิศวกรรมไฟฟ้าสื่อสาร สนใจงานด้าน การพัฒนาเว็บไซต์ เป็นพิเศษ และกำลังมองหาโอกาศฝึกงานในสายนี้

ติดต่อฉัน

จุดแข็งและสิ่งที่กำลังพัฒนา

จุดแข็ง

  • มีพื้นฐานการคิดแบบวิศวกรรม วิเคราะห์และแก้ปัญหาเป็นระบบ
  • เรียนรู้เทคโนโลยีใหม่ได้เร็ว และปรับตัวกับงานที่ไม่คุ้นเคยได้ดี
  • เข้าใจภาพรวมทั้งระบบ ไม่ได้มองเฉพาะหน้าเว็บ
  • ใส่ใจรายละเอียดและชอบหาสาเหตุของปัญหาให้เข้าใจจริง

สิ่งที่กำลังพัฒนา

  • ประสบการณ์ด้าน Web Development ยังอยู่ในช่วงต่อยอด — ฝึกพัฒนาโปรเจกต์จริงอย่างสม่ำเสมอเพื่อเพิ่มความเชี่ยวชาญ
  • ยังไม่ชำนาญการเชื่อมต่อ Frontend กับ Backend — ฝึกใช้งาน API และ Database ผ่านโปรเจกต์ส่วนตัว
  • ยังอยู่ระหว่างพัฒนาความคล่องตัวในการใช้เครื่องมือสำหรับงานพัฒนา — ฝึกใช้ Git, GitHub และจัดโครงสร้างโค้ดให้เป็นระบบ
  • ยังไม่ชำนาญภาษาอังกฤษเชิงเทคนิค — ฝึกอ่าน Documentation และบทความด้าน Web Development เป็นประจำ
